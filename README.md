Stormhsield Configuration assistant è un tool open e non ufficiale che nasce con lo scopo di automatizzare operazioni ripetitive e fornire una configurazione dei firewall Stormshield pronta all'uso in pochi secondi. 

###Installazione

Per l'uso di SCA è sufficente scaricare il repo e lanciare make install dalla root directory del progetto. Per l'esecuzione è sufficente lanciare il comando make run

Nota bene: Il Quick Config Wizard fa riferimento all'ip di default 10.0.0.254, pertanto l'host deve essere nella network 10.0.0.0/8
